# ADO TURF INTELLIGENT

Application Android d'analyse des courses PMU.

## Fonctionnalités

- Analyse Option 1
- Analyse Option 6
- Enregistrement des analyses
- Historique des chevaux
- Base de données Wado_turf.json

## Fichiers principaux

- main.py
- buildozer.spec
- requirements.txt
- Wado_turf.json

## Compilation

L'application est prévue pour une compilation Android avec Kivy et Buildozer.
